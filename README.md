# Витрина цитатника

Сервис-прослойка между читателями и каталогом цитат.

## Запуск

```bash
docker build -t vitrina .
docker run --rm -p 8000:8000 --memory=256m --cpus=0.5 vitrina
```

Проверка:
```bash
curl http://localhost:8000/health
```

## Ручки

| Метод | Путь | Назначение |
|---|---|---|
| GET | /health | Проверка живости |
| POST | /catalog/source | Установить адрес каталога |
| POST | /import | Принять снимок каталога |
| PUT | /catalog/{id} | Добавить/заменить цитату |
| DELETE | /catalog/{id} | Снять с публикации |
| GET | /quotes/{id} | Чтение цитаты |
| GET | /stats | Сводка |

## Ключевые решения

- Записи хранятся как готовые JSON-байты — экономия памяти (340k записей ≈ 100 МБ вместо 300+ МБ).
- Снимок парсится построчно, без промежуточного списка из 340 000 dict'ов.
- Клиент каталога: семафор (4 параллельных), single-flight, экспоненциальный backoff, уважение `Retry-After`.
- 404 не кэшируется — редакция постоянно заводит новые цитаты.
- Снятые через DELETE хранятся в отдельном set до следующего снимка.
